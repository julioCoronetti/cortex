# Cortex

Base de conhecimento pessoal com RAG.

## Stack

- Frontend: React + Vite (PWA)
- Backend: Lambda + API Gateway (Node.js)
- Banco: DynamoDB
- Vector: DynamoDB + busca em Lambda
- Auth: Cognito
- Deploy: S3 + CloudFront

## Estrutura

```
cortex/
├── frontend/    # React + Vite
├── api/         # Lambda functions
└── template.yaml
```
