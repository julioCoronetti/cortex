# Project Rules

## Code Style
- No comments in code
- No over-engineering (no shared/, infra/ folders)
- Simple, decoupled, easy to replicate
- Descriptive, standardized names

## Workflow
- Simplicity > perfect organization
- Only commit when explicitly asked
- Confirm before changing stack
- Ask before any external action

## Structure
- `api/` - Rust Lambda functions
- `client/` - React frontend
- `.opencode/` - Agent configs and skills
